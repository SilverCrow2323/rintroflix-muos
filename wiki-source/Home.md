# RintrofliX — quick guide

RintrofliX is a controller-first media-centre project for muOS and the Anbernic H700 handheld family. The documented 2.6.0 baseline covers live TV, a local video library, playlists, XMLTV guide data, playback controls and add-ons.

> [!IMPORTANT]
> **MUST KNOW!!** The repository README states that the 2.6.0 source mirror is still partial. A complete application package cannot be assumed from this repository's source ZIP. Check [Releases](https://github.com/SilverCrow2323/rintroflix-muos/releases) for a complete, versioned `.muxapp` before installing.

## The main areas

- **Watch TV** browses channels, groups, favourites, search and the programme guide.
- **Local Library** browses user-selected folders on SD or USB storage.
- **Add-ons** extends the app through versioned APIs.
- **Sources** manages playlists and guide providers.
- **Settings** controls interface and playback preferences.
